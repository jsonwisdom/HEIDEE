- directories first
- public-safe only
- `authority: false`
- source work is summarized, not silently inferred
- observations, declarations, generated concepts, and verified artifacts remain distinct
- no secrets, addresses, phone numbers, private identifiers, or sensitive records
- each day uses `YYYY-MM-DD/`
- each daily directory contains a human-readable `README.md` and machine-readable `manifest.json`
- JoySpace may adapt the material for learning, creativity, replay, or family continuity
- Mrs. Wisdom may observe/steward the JoySpace family layer, but no identity, consent, or authority is inferred by repository structure

`OBSERVED | DECLARED | GENERATED | VERIFIED | DELTA | HOLD | UNKNOWN`

The directory is a continuity surface, not a source of authority.
