Kids can read two public documents, check their exact bytes, and explain what changed. Files are processed on this device. You can save a witness-copy briefing for a trusted adult to review. No upload, account, or wallet required.

Important: A different SHA-256 hash proves the file bytes differ. It does not prove a law, policy, or meaning changed. A matching hash proves identical bytes, not that a source is official.
