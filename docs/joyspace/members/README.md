# JoySpace Members

Every JoySpace member requires a site-facing docs surface beneath `docs/joyspace/members/`.

Contract:

- public-safe only
- `authority: false`
- stewardship only
- member docs feed the JoySpace site
- receipts, quests, schemas, and replay artifacts remain discoverable from the member surface

Member directories should use stable lowercase slugs and contain at minimum a `README.md` entrypoint.
