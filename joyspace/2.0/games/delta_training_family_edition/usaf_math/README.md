# USAF-Style Math

Directory contract for aviation/logistics-flavored civilian math scenarios inside JoySpace.

Math ladder admitted here:
`M0 COUNTING -> M1 ARITHMETIC -> M2 RATIOS_RATES -> M3 UNIT_CONVERSION -> M4 ALGEBRA -> M5 GEOMETRY -> M6 VECTORS -> M7 FUNCTIONS -> M8 DELTA -> M9 PROBABILITY -> M10 STATISTICS -> M11 GRAPH_THEORY -> M12 OPTIMIZATION -> M13 RECURSION`

Hard boundaries:
- `USAF_STYLE_CONTEXT != USAF_CURRICULUM`
- `FAMILY_GAME != MILITARY_TRAINING`
- `MATH_PROBLEM != OPERATIONAL_ORDER`
- `OPTIMAL_RESULT != AUTHORIZATION`
- `DELTA_DETECTED != CAUSE_PROVEN`

Dice may select a problem class but never an answer, fact, verdict, or authority state.
