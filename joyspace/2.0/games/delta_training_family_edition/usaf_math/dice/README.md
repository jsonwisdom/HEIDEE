# DELTA Dice

Directory contract for deterministic problem-class selection inside DELTA Training Family Edition / USAF-Style Math.

This directory may contain versioned dice selector tables. Dice are routing mechanics only.

Hard boundaries:

```text
DICE_ROLL != ANSWER
DICE_ROLL != FACT
DICE_ROLL != EVIDENCE
DICE_ROLL != VERDICT
DICE_ROLL != AUTHORITY
PROBLEM_CLASS != USAF_CURRICULUM
FAMILY_GAME != MILITARY_TRAINING
MATH_PROMPT != OPERATIONAL_ORDER
SCORE != SCHOOL_GRADE
```

A die result may select a bounded civilian math problem class. The resulting mission must still collapse into `family_edition_receipt_v0_1.schema.json` and preserve all human-authorization, privacy, family-fact, institutional-adoption, and authority boundaries.

No mission result, learner performance, family fact, military status, institutional adoption, or authority is created by a dice table.
