# Family Dice — JoySpace Replay Lane

This directory stores bounded family-game rounds as replayable play receipts.

## Rules

- dice observations are game inputs, not evidence about a person
- `ROLL_TOTAL != SCORE_DELTA` unless a separately defined scoring rule establishes the mapping
- actor/cast draws do not create family relationships
- BossBre privacy checks govern exposure of protected actor details
- HEIDEE may double-check game-state typing but does not create authority
- game receipts may be replayed without becoming genealogy, biography, or public-person evidence

```text
GAME_STATE != FAMILY_FACT
DICE_ROLL != VERDICT
CAST_DRAW != RELATIONSHIP_EDGE
PRIVACY_CHECK != IDENTITY_PROOF
```
