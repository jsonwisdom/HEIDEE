# Heidee's Family — Typed Layer

This directory stores versioned family claims without collapsing role, position, or kinship.

## Types

- `ROLE_CARD` = functional/play role
- `PORCH_NODE` = structural position
- `RELATIONSHIP_CLAIM` = asserted kinship/relationship edge with independent status

A relationship object may exist while verification remains `HOLD`.

No count in this directory is a derived count of people or family members unless explicitly evidenced and separately verified.

Promotion states: `SUPPORTED`, `REJECTED`, `HOLD`.
